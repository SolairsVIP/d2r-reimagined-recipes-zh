# 中文配方查询页实施计划

**目标：** 将用户指定的 D2R Reimagined 配方资料整理为完整、可搜索的中文静态网站，并尽可能发布到 GitHub Pages。

**架构：** 提取原始配方表中的材料与结果，保留原表的分组、顺序和限制说明；用本地中文数据驱动无构建步骤的静态页面。网站使用相对路径，兼容 GitHub Pages 项目子路径和本地文件打开。

**验证：** 检查原表数量、关键配方、中文覆盖率、搜索和分类筛选；在桌面及移动尺寸验证布局。发布前确认仓库和凭据可用。

1. 从官方配方源提取所有配方行和适用说明，编制中文术语表。
2. 编写并运行数据与筛选行为测试，再实现数据、界面与交互。
3. 核对数据完整性、翻译和页面显示；验证相对路径与离线访问。
4. 在有 GitHub 凭据的情况下创建仓库、推送并启用 Pages；否则说明具体缺口。
